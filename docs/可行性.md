# 完全可行，而且这是个很合适的 iced 练手项目

先说一个能让项目难度大幅降低的关键点：
> **MP4 和 MOV 本质上是"近亲"**——两者都源自 QuickTime / ISO BMFF 容器格式，只是盒子结构和 brand 不同。所以 MP4 ⇄ MOV 绝大多数情况下**不需要重新编码**，只是"换壳"（remux）：用 ffmpeg 的 `-c copy` 把音视频流原样搬到新容器里即可。速度接近文件复制，完全无损。

## 技术选型

| 转换引擎方案 | 说明 | 建议 |
|---|---|---|
| 子进程调用 `ffmpeg` | `-c copy` 重封装 | ✅ 首选，简单可靠 |
| `ffmpeg-sidecar` crate | 帮你定位/下载 ffmpeg 二进制，还提供类型化的进度事件 | 想省事可用 |
| `ffmpeg-next` 等 FFI 绑定 | 进程内调用 libav* | ❌ 交叉编译和构建都很痛苦 |
| 纯 Rust（`mp4` 等 crate） | 自己解析/写入盒子 | 进阶玩法，MOV 支持不完善 |
UI 侧的分工：**iced 负责界面（Elm 架构）**，**rfd 负责文件选择对话框**，**tokio 负责异步跑 ffmpeg 进程**（不阻塞 UI），进度通过 iced 的 `Task::stream` 推回界面。

## 最小可用示例（iced 0.13 的 API，思路各版本通用）

```toml
[dependencies]
iced = { version = "0.13", features = ["tokio"] }
rfd = { version = "0.15", features = ["tokio"] }
tokio = { version = "1", features = ["process", "io-util", "rt"] }
futures = "0.3"
```
```rust
use futures::channel::mpsc::Sender;
use iced::{
    alignment,
    widget::{button, column, progress_bar, text},
    Element, Length, Task,
};
use tokio::io::AsyncBufReadExt;
fn main() -> iced::Result {
    iced::application("Vidly", App::update, App::view)
        .default_size((480.0, 360.0))
        .run()
}
#[derive(Default)]
struct App {
    input: Option<String>,
    output: Option<String>,
    busy: bool,
    progress: f32,
    status: String,
}
#[derive(Debug, Clone)]
enum Message {
    PickInput,
    InputPicked(Option<String>),
    Convert,
    Tick(f32),
    Finished(Result<(), String>),
}
impl App {
    fn update(&mut self, msg: Message) -> Task<Message> {
        match msg {
            Message::PickInput => Task::perform(pick_file(), Message::InputPicked),
            Message::InputPicked(None) => Task::none(),
            Message::InputPicked(Some(path)) => {
                self.input = Some(path.clone());
                self.output = Some(flip_ext(&path)); // 自动推导输出路径
                self.status.clear();
                Task::none()
            }
            Message::Convert => {
                let (Some(input), Some(output)) = (self.input.clone(), self.output.clone())
                else { return Task::none() };
                self.busy = true;
                self.progress = 0.0;
                self.status = "转换中…".into();
                Task::stream(move |tx| async move {
                    let result = convert(input, output, tx.clone()).await;
                    let _ = tx.send(Message::Finished(result)).await;
                })
            }
            Message::Tick(p) => { self.progress = p; Task::none() }
            Message::Finished(Ok(())) => {
                self.busy = false; self.progress = 100.0;
                self.status = "✅ 完成".into();
                Task::none()
            }
            Message::Finished(Err(e)) => {
                self.busy = false;
                self.status = format!("❌ {e}");
                Task::none()
            }
        }
    }
    fn view(&self) -> Element<'_, Message> {
        column![
            text("Vidly").size(30),
            button(fill_text(self.input.as_deref().unwrap_or("选择文件（MP4 / MOV）")))
                .on_press_maybe((!self.busy).then_some(Message::PickInput))
                .padding(10)
                .width(Length::Fill),
            text(self.output.as_deref().unwrap_or(" ")).size(12),
            progress_bar(0.0..=100.0, self.progress).width(Length::Fill),
            button(fill_text("开始转换"))
                .on_press_maybe(
                    (!self.busy && self.input.is_some()).then_some(Message::Convert)
                )
                .padding(12)
                .width(Length::Fill),
            text(self.status.as_str()),
        ]
        .spacing(14)
        .padding(24)
        .align_x(alignment::Horizontal::Center)
        .into()
    }
}
fn fill_text(label: &str) -> Element<'_, Message> {
    column![text(label)]
        .width(Length::Fill)
        .align_x(alignment::Horizontal::Center)
        .into()
}
async fn pick_file() -> Option<String> {
    rfd::AsyncFileDialog::new()
        .set_title("选择视频文件")
        .add_filter("视频", &["mp4", "mov"])
        .pick_file()
        .await
        .map(|h| h.path().display().to_string())
}
/// mp4 → mov / mov → mp4
fn flip_ext(path: &str) -> String {
    let p = std::path::Path::new(path);
    let is_mov = p.extension().and_then(|e| e.to_str())
        .is_some_and(|e| e.eq_ignore_ascii_case("mov"));
    let ext = if is_mov { "mp4" } else { "mov" };
    let stem = p.file_stem().and_then(|s| s.to_str()).unwrap_or("output");
    p.with_file_name(format!("{stem}.{ext}")).display().to_string()
}
async fn probe_duration(path: &str) -> Result<f64, String> {
    let out = tokio::process::Command::new("ffprobe")
        .args(["-v", "error", "-show_entries", "format=duration",
               "-of", "default=noprint_wrappers=1:nokey=1", path])
        .output().await
        .map_err(|e| format!("无法启动 ffprobe：{e}，请先安装 FFmpeg"))?;
    String::from_utf8_lossy(&out.stdout).trim().parse()
        .map_err(|_| "读取时长失败".into())
}
async fn convert(input: String, output: String, tx: Sender<Message>) -> Result<(), String> {
    let total = probe_duration(&input).await?;
    let mut child = tokio::process::Command::new("ffmpeg")
        .args(["-y", "-i", &input,
               "-c", "copy",              // ★ 核心：只换容器不重编码 → 无损、飞快
               "-progress", "pipe:1", "-nostats",
               &output])
        .stdout(std::process::Stdio::piped())
        .stderr(std::process::Stdio::piped())
        .spawn().map_err(|e| format!("无法启动 ffmpeg：{e}"))?;
    let mut lines = tokio::io::BufReader::new(child.stdout.take().unwrap()).lines();
    while let Some(line) = lines.next_line().await.map_err(|e| e.to_string())? {
        // 坑：out_time_ms 名字是历史遗留，实际单位是微秒
        if let Some(v) = line.strip_prefix("out_time_ms=") {
            if let Ok(us) = v.trim().parse::<f64>() {
                let pct = (us / 1e6 / total * 100.0) as f32;
                let _ = tx.send(Message::Tick(pct.clamp(0.0, 100.0))).await;
            }
        }
    }
    let status = child.wait().await.map_err(|e| e.to_string())?;
    if status.success() { Ok(()) } else { Err(format!("ffmpeg 异常退出：{status}")) }
}
```

## 值得再加的功能

- **批量转换**：文件列表 + 每项独立进度条，串行或并发跑队列
- **取消按钮**：保存 `Child` 句柄，取消时 `kill()`
- **拖拽进窗口**：订阅 iced 的 `window::Event::FileDropped`
- **完成后打开输出文件夹**：`open` crate
- **输出 MP4 时加 `-movflags +faststart`**：moov 前置，方便流式播放

## 几个坑提前说

1. **ffmpeg 依赖**：工具本质是 ffmpeg 的"壳"。要么启动时检测 PATH 并提示安装，要么分发时随包附带各平台二进制（注意许可证：闭源分发请用 LGPL 构建的 ffmpeg，remux 用不到编码器，LGPL 完全够；常见发行版多为 GPL 构建）
2. **进度条一闪而过是正常的**：remux 是 I/O 级速度，几 GB 的文件也就几秒
3. **个别编码的兼容性**：AV1/VP9 塞进 MOV 能转成功，但 QuickTime Player 未必认——这不是转换的问题
4. **Linux 上的 rfd** 默认走 GTK，需要系统依赖，可换 `xdg-portal` feature
5. **Windows release** 记得加 `#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]`，避免拖个控制台窗口
6. **iced 的 API 迭代较快**（0.12→0.13 就有 `Command`→`Task` 的大改），写之前对准你手上的版本查文档

## 工作量估计

- MVP（单文件 + 进度条）：一个晚上
- 打磨版（批量、取消、拖拽、打包分发 ffmpeg）：两三个周末
