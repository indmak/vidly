# Vidly：
Video + -ly，短、好记，像现代开源项目命名，

三个桌面系统覆盖

开源

定位：便捷无损的MP4转MOV，以及mov转MP4小工具

网页关键字必须包含：mp4 to mov，mov to mo4

gitc仓库：https://github.com/indmak/vidly
以配置ssh，用ssh上传下载

readme.md文档重点做一下，参照成熟开源项目，需要哪些文案，内容，链接（链接到官网和微软商店），截屏图片。

语言包：英语默认，法语，德语，西班牙语，俄语，日语，韩语，简体中文
8种语言，随系统自动匹配。匹配不到的自动选择英语。
