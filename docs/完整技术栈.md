# Vidly · 完整技术栈与实现

## 一、技术栈总览

| 层 | 选型 | 版本¹ | 职责 |
|---|---|---|---|
| GUI 框架 | `iced`（`tokio` feature） | 0.13 | Elm 架构界面、订阅（拖拽/快捷键）、异步任务 |
| 异步运行时 | `tokio` | 1.x | 子进程、文件 IO，不阻塞 UI |
| 任务取消 | `tokio-util` → `CancellationToken` | 0.7 | 单项/全部取消，杀掉 ffmpeg 子进程 |
| 文件对话框 | `rfd`（`tokio` feature） | 0.15 | 添加文件 / 选择输出目录 |
| 转换引擎 | `ffmpeg` / `ffprobe` 子进程 | 7.x | `-c copy` 无损重封装 + 进度探测 |
| 打开文件 | `opener`（`reveal`） | 0.7 | 在文件管理器中定位输出文件 |
| 配置持久化 | `serde` + `serde_json` + `dirs` | 1 / 1 / 6 | 输出目录、覆盖策略、并发数、faststart |
| 错误处理 | `thiserror` | 2 | 类型化错误（取消/失败/探测失败分开处理） |
| 日志 | `tracing` + `tracing-subscriber` | 0.1 / 0.3 | `RUST_LOG=debug` 排查 ffmpeg 问题 |
¹ 版本是我能确认的最新稳定版（iced 迭代很快，动手前建议 `cargo search iced` 确认；若 `dirs` 报错改回 `5` 即可，本项目只用 `config_dir`）。
**已采纳的完整功能**：批量队列+并发调度、单项/全部取消、拖拽+文件夹自动展开、三种覆盖策略、faststart、打开输出位置、ffmpeg 自动探测（含便携同目录/macOS 特殊路径）、设置持久化、快捷键 Ctrl+O / Ctrl+Enter、Windows 无控制台。

```rust
use std::path::{Path, PathBuf};
/// 支持的输入格式：mp4/m4v → mov；mov → mp4
pub const SUPPORTED: [&str; 3] = ["mp4", "mov", "m4v"];
pub fn is_supported(p: &Path) -> bool {
    p.extension()
        .and_then(|e| e.to_str())
        .is_some_and(|e| SUPPORTED.iter().any(|s| e.eq_ignore_ascii_case(s)))
}
pub fn flip_ext(path: &Path) -> &'static str {
    let is_mov = path
        .extension()
        .and_then(|e| e.to_str())
        .is_some_and(|e| e.eq_ignore_ascii_case("mov"));
    if is_mov { "mp4" } else { "mov" }
}
/// 计划输出路径：输出目录（缺省为源文件目录）+ 原文件名 + 新扩展名
pub fn planned_output(path: &Path, out_dir: Option<&Path>) -> PathBuf {
    let dir = out_dir
        .map(|d| d.to_path_buf())
        .unwrap_or_else(|| path.parent().map(|p| p.to_path_buf()).unwrap_or_default());
    let stem = path.file_stem().and_then(|s| s.to_str()).unwrap_or("output");
    dir.join(format!("{stem}.{}", flip_ext(path)))
}
/// 自动重命名：name.mp4 → name (1).mp4 → name (2).mp4 …
pub fn unique_path(mut p: PathBuf) -> PathBuf {
    if !p.exists() {
        return p;
    }
    let stem = p.file_stem().and_then(|s| s.to_str()).unwrap_or("output").to_owned();
    let ext = p.extension().and_then(|e| e.to_str()).map(|e| format!(".{e}")).unwrap_or_default();
    let parent = p.parent().map(|d| d.to_path_buf()).unwrap_or_default();
    for n in 1.. {
        p = parent.join(format!("{stem} ({n}){ext}"));
        if !p.exists() {
            return p;
        }
    }
    unreachable!()
}
```

```rust
use serde::{Deserialize, Serialize};
use std::path::PathBuf;
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, Default)]
pub enum OverwritePolicy {
    #[default]
    Rename,    // 自动重命名 name (1).mov
    Overwrite, // 覆盖
    Skip,      // 跳过已存在
}
impl std::fmt::Display for OverwritePolicy {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        f.write_str(match self {
            OverwritePolicy::Rename => "自动重命名",
            OverwritePolicy::Overwrite => "覆盖",
            OverwritePolicy::Skip => "跳过已存在",
        })
    }
}
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Config {
    pub output_dir: Option<PathBuf>, // None = 与源文件同目录
    pub overwrite: OverwritePolicy,
    pub concurrency: usize,
    pub faststart: bool,
}
impl Default for Config {
    fn default() -> Self {
        Self { output_dir: None, overwrite: OverwritePolicy::default(), concurrency: 2, faststart: true }
    }
}
fn config_path() -> Option<PathBuf> {
    dirs::config_dir().map(|d| d.join("vidly").join("config.json"))
}
pub async fn load() -> Config {
    let Some(path) = config_path() else { return Config::default() };
    match tokio::fs::read_to_string(&path).await {
        Ok(s) => serde_json::from_str(&s).unwrap_or_else(|e| {
            tracing::warn!("配置解析失败，使用默认值: {e}");
            Config::default()
        }),
        Err(_) => Config::default(),
    }
}
pub async fn save(cfg: &Config) {
    let Some(path) = config_path() else { return };
    if let Some(parent) = path.parent() {
        let _ = tokio::fs::create_dir_all(parent).await;
    }
    match serde_json::to_string_pretty(cfg) {
        Ok(s) => {
            if let Err(e) = tokio::fs::write(&path, s).await {
                tracing::warn!("保存配置失败: {e}");
            }
        }
        Err(e) => tracing::warn!("序列化配置失败: {e}"),
    }
}
```

### src/convert.rs

```rust
use std::path::{Path, PathBuf};
use std::process::Stdio;
use std::time::{Duration, Instant};
use thiserror::Error;
use tokio::io::AsyncBufReadExt;
use tokio_util::sync::CancellationToken;
#[derive(Debug, Clone, Error)]
pub enum ConvertError {
    #[error("已取消")]
    Canceled,
    #[error("源文件不存在")]
    InputMissing,
    #[error("读取时长失败（文件可能损坏）")]
    ProbeFailed,
    #[error("无法启动 ffmpeg：{0}")]
    Spawn(String),
    #[error("ffmpeg 异常退出（{code}）：{tail}")]
    Exit { code: i32, tail: String },
    #[error(transparent)]
    Io(#[from] std::io::Error),
}
#[derive(Debug, Clone)]
pub struct FfmpegPaths {
    pub ffmpeg: PathBuf,
    pub ffprobe: PathBuf,
}
#[derive(Debug, Clone)]
pub struct Request {
    pub input: PathBuf,
    pub output: PathBuf,
    pub faststart: bool,
}
/// 定位 ffmpeg/ffprobe：① exe 同目录（便携分发）② PATH ③ 常见安装目录。
/// ③ 很重要：macOS 从 Finder 启动的 GUI 程序拿不到用户 shell 的 PATH，
/// Homebrew（/opt/homebrew/bin）装的 ffmpeg 会找不到。
pub fn find_ffmpeg() -> Option<FfmpegPaths> {
    Some(FfmpegPaths {
        ffmpeg: find_binary("ffmpeg")?,
        ffprobe: find_binary("ffprobe")?,
    })
}
const COMMON_DIRS: &[&str] = &[
    "/opt/homebrew/bin",          // macOS Apple Silicon
    "/usr/local/bin",             // macOS Intel / Linux 手动安装
    "/opt/local/bin",             // MacPorts
    "/run/current-system/sw/bin", // NixOS
];
fn find_binary(name: &str) -> Option<PathBuf> {
    #[cfg(windows)]
    let name = format!("{name}.exe");
    if let Ok(exe) = std::env::current_exe() {
        if let Some(dir) = exe.parent() {
            let candidate = dir.join(&name);
            if candidate.is_file() {
                return Some(candidate);
            }
        }
    }
    if let Some(path) = std::env::var_os("PATH") {
        if let Some(found) = std::env::split_paths(&path)
            .map(|dir| dir.join(&name))
            .find(|p| p.is_file())
        {
            return Some(found);
        }
    }
    COMMON_DIRS
        .iter()
        .map(|dir| Path::new(dir).join(&name))
        .find(|p| p.is_file())
}
async fn probe_duration(ffprobe: &Path, input: &Path) -> Result<f64, ConvertError> {
    let out = tokio::process::Command::new(ffprobe)
        .args([
            "-v", "error",
            "-show_entries", "format=duration",
            "-of", "default=noprint_wrappers=1:nokey=1",
        ])
        .arg(input)
        .output()
        .await
        .map_err(|_| ConvertError::ProbeFailed)?;
    String::from_utf8_lossy(&out.stdout)
        .trim()
        .parse::<f64>()
        .map_err(|_| ConvertError::ProbeFailed)
}
/// 执行一次 remux：只更换容器（MP4/MOV 同源，均为 ISO BMFF），
/// 音视频流原样搬运 → 无损、接近文件复制的速度。
pub async fn run<P>(paths: &FfmpegPaths, req: Request, cancel: CancellationToken, progress: P)
    -> Result<Duration, ConvertError>
where
    P: Fn(f32) + Send + 'static,
{
    let started = Instant::now();
    if !req.input.is_file() {
        return Err(ConvertError::InputMissing);
    }
    let total = probe_duration(&paths.ffprobe, &req.input).await?;
    if let Some(dir) = req.output.parent() {
        tokio::fs::create_dir_all(dir).await?;
    }
    let to_mp4 = req.output.extension().and_then(|e| e.to_str())
        .is_some_and(|e| e.eq_ignore_ascii_case("mp4"));
    let mut cmd = tokio::process::Command::new(&paths.ffmpeg);
    cmd.args(["-y", "-hide_banner", "-loglevel", "error", "-nostdin"]) // GUI 程序必须 -nostdin
        .arg("-i").arg(&req.input)
        // 字幕/数据流在两容器间兼容性差，只搬视频+音频
        .args(["-c", "copy", "-map", "0:v?", "-map", "0:a?"])
        .args(["-progress", "pipe:1", "-nostats"]);
    if to_mp4 && req.faststart {
        cmd.args(["-movflags", "+faststart"]); // moov 前置，利于流式播放
    }
    cmd.arg(&req.output)
        .stdout(Stdio::piped())
        .stderr(Stdio::piped());
    let mut child = cmd.spawn().map_err(|e| ConvertError::Spawn(e.to_string()))?;
    // 单独收 stderr，避免管道塞满死锁；失败时取末尾几行展示
    let stderr_task = {
        let mut stderr = child.stderr.take().expect("piped");
        tokio::spawn(async move {
            use tokio::io::AsyncReadExt;
            let mut buf = String::new();
            let _ = stderr.read_to_string(&mut buf).await;
            buf
        })
    };
    let mut lines = tokio::io::BufReader::new(child.stdout.take().expect("piped")).lines();
    loop {
        tokio::select! {
            _ = cancel.cancelled() => {
                let _ = child.kill().await;
                let _ = child.wait().await;
                let _ = tokio::fs::remove_file(&req.output).await; // 清理半成品
                return Err(ConvertError::Canceled);
            }
            line = lines.next_line() => {
                let Some(line) = line? else { break };
                // 坑：out_time_ms 是历史遗留命名，单位实际是微秒
                if let Some(v) = line.strip_prefix("out_time_ms=") {
                    if let Ok(us) = v.trim().parse::<f64>() {
                        if total > 0.0 {
                            let pct = (us / 1_000_000.0 / total * 100.0) as f32;
                            progress(pct.clamp(0.0, 100.0));
                        }
                    }
                }
            }
        }
    }
    let status = child.wait().await?;
    let stderr = stderr_task.await.unwrap_or_default();
    if !status.success() {
        let _ = tokio::fs::remove_file(&req.output).await;
        let tail = stderr.lines().rev().take(3).collect::<Vec<_>>().join(" | ");
        return Err(ConvertError::Exit { code: status.code().unwrap_or(-1), tail });
    }
    Ok(started.elapsed())
}
```

### src/app.rs

```rust
use std::collections::{HashMap, VecDeque};
use std::path::PathBuf;
use std::sync::atomic::{AtomicU64, Ordering};
use iced::{
    alignment::{Horizontal, Vertical},
    widget::{button, checkbox, column, container, horizontal_space, pick_list,
             progress_bar, scrollable, slider, text, Column},
    Element, Length, Subscription, Task,
};
use tokio_util::sync::CancellationToken;
use crate::config::{self, Config, OverwritePolicy};
use crate::convert::{self, ConvertError, FfmpegPaths, Request};
use crate::util;
pub type ItemId = u64;
static NEXT_ID: AtomicU64 = AtomicU64::new(1);
#[derive(Debug, Clone)]
pub enum Phase {
    Queued,
    Running { progress: f32 },
    Done { secs: f64 },
    Failed(String),
    Canceled,
    Skipped,
}
#[derive(Debug, Clone)]
pub struct Item {
    pub id: ItemId,
    pub input: PathBuf,
    pub output: PathBuf, // 启动那一刻才按覆盖策略最终确定
    pub phase: Phase,
}
#[derive(Debug, Clone)]
pub enum Message {
    Init(Option<FfmpegPaths>, Config),
    PickFiles,
    FilesPicked(Vec<PathBuf>),
    FilesDropped(Vec<PathBuf>),
    PickOutputDir,
    OutputDirPicked(Option<PathBuf>),
    ResetOutputDir,
    OverwriteChanged(OverwritePolicy),
    ConcurrencyChanged(usize),
    SaveSettings,
    FaststartToggled(bool),
    StartAll,
    StartItem(ItemId),
    Cancel(ItemId),
    CancelAll,
    Remove(ItemId),
    ClearFinished,
    ClearAll,
    Progress(ItemId, f32),
    Finished(ItemId, Result<f64, ConvertError>),
    OpenOutput(ItemId),
    Ignore,
}
#[derive(Default)]
pub struct App {
    items: Vec<Item>,
    tokens: HashMap<ItemId, CancellationToken>, // 运行中项目的取消句柄
    ffmpeg: Option<FfmpegPaths>,
    config: Config,
    status: String,
}
impl App {
    pub fn init() -> Task<Message> {
        Task::perform(
            async { (convert::find_ffmpeg(), config::load().await) },
            |(ffmpeg, cfg)| Message::Init(ffmpeg, cfg),
        )
    }
    // ---------- update ----------
    pub fn update(&mut self, message: Message) -> Task<Message> {
        match message {
            Message::Init(paths, mut cfg) => {
                cfg.concurrency = cfg.concurrency.clamp(1, 8);
                self.config = cfg;
                self.ffmpeg = paths;
                if self.ffmpeg.is_none() {
                    self.status = "未检测到 ffmpeg / ffprobe：请安装 FFmpeg，\
                                   或把 ffmpeg(.exe)、ffprobe(.exe) 与本程序放同一目录后重启".into();
                }
                Task::none()
            }
            Message::PickFiles => Task::perform(pick_files(), Message::FilesPicked),
            Message::FilesPicked(paths) | Message::FilesDropped(paths) => {
                self.add_files(paths);
                Task::none()
            }
            Message::PickOutputDir => Task::perform(pick_dir(), Message::OutputDirPicked),
            Message::OutputDirPicked(Some(dir)) => {
                self.config.output_dir = Some(dir);
                self.relocate_outputs();
                self.save_config()
            }
            Message::OutputDirPicked(None) => Task::none(),
            Message::ResetOutputDir => {
                self.config.output_dir = None;
                self.relocate_outputs();
                self.save_config()
            }
            Message::OverwriteChanged(p) => {
                self.config.overwrite = p;
                self.save_config()
            }
            Message::ConcurrencyChanged(n) => {
                self.config.concurrency = n;
                self.pump() // 调大并发立即补位
            }
            Message::SaveSettings => self.save_config(), // 滑块松手才落盘
            Message::FaststartToggled(b) => {
                self.config.faststart = b;
                self.save_config()
            }
            Message::StartAll => {
                // 失败/取消/跳过的一并重置后统一启动
                for item in &mut self.items {
                    if matches!(item.phase, Phase::Failed(_) | Phase::Canceled | Phase::Skipped) {
                        item.phase = Phase::Queued;
                    }
                }
                self.start()
            }
            Message::StartItem(id) => {
                if let Some(item) = self.items.iter_mut().find(|i| i.id == id) {
                    item.phase = Phase::Queued;
                    item.output = util::planned_output(&item.input, self.config.output_dir.as_deref());
                }
                self.start()
            }
            Message::Cancel(id) => {
                if let Some(t) = self.tokens.get(&id) { t.cancel(); }
                Task::none()
            }
            Message::CancelAll => {
                for t in self.tokens.values() { t.cancel(); }
                Task::none()
            }
            Message::Remove(id) => {
                self.cancel_token(&id);
                self.items.retain(|i| i.id != id);
                Task::none()
            }
            Message::ClearFinished => {
                self.items.retain(|i| !matches!(
                    i.phase, Phase::Done { .. } | Phase::Failed(_) | Phase::Canceled | Phase::Skipped
                ));
                Task::none()
            }
            Message::ClearAll => {
                let ids: Vec<_> = self.items.iter().map(|i| i.id).collect();
                for id in ids { self.cancel_token(&id); }
                self.items.clear();
                Task::none()
            }
            Message::Progress(id, p) => {
                if let Some(item) = self.items.iter_mut().find(|i| i.id == id) {
                    if let Phase::Running { progress } = &mut item.phase {
                        *progress = p;
                    }
                }
                Task::none()
            }
            Message::Finished(id, result) => {
                self.tokens.remove(&id);
                if let Some(item) = self.items.iter_mut().find(|i| i.id == id) {
                    item.phase = match result {
                        Ok(secs) => Phase::Done { secs },
                        Err(ConvertError::Canceled) => Phase::Canceled,
                        Err(e) => Phase::Failed(e.to_string()),
                    };
                }
                self.pump() // 空出一个坑，补下一个
            }
            Message::OpenOutput(id) => {
                if let Some(item) = self.items.iter().find(|i| i.id == id) {
                    if let Err(e) = opener::reveal(&item.output) {
                        self.status = format!("打开失败：{e}");
                    }
                }
                Task::none()
            }
            Message::Ignore => Task::none(),
        }
    }
    // ---------- 调度 ----------
    fn start(&mut self) -> Task<Message> {
        if self.ffmpeg.is_none() {
            self.status = "未检测到 FFmpeg，无法转换（见顶部提示）".into();
            return Task::none();
        }
        if !self.items.iter().any(|i| matches!(i.phase, Phase::Queued)) {
            return Task::none();
        }
        self.pump()
    }
    /// 把排队项目塞进空闲槽位（并发数受配置限制）
    fn pump(&mut self) -> Task<Message> {
        let Some(paths) = self.ffmpeg.clone() else { return Task::none() };
        let mut tasks = Vec::new();
        loop {
            if self.running_count() >= self.config.concurrency.max(1) { break; }
            let Some(id) = self.items.iter()
                .find(|i| matches!(i.phase, Phase::Queued))
                .map(|i| i.id)
            else { break };
            let item = self.items.iter_mut().find(|i| i.id == id).unwrap();
            // 此刻才应用覆盖策略
            match self.config.overwrite {
                OverwritePolicy::Skip if item.output.exists() => {
                    item.phase = Phase::Skipped;
                    continue;
                }
                OverwritePolicy::Rename => item.output = util::unique_path(item.output.clone()),
                _ => {}
            }
            let req = Request {
                input: item.input.clone(),
                output: item.output.clone(),
                faststart: self.config.faststart,
            };
            item.phase = Phase::Running { progress: 0.0 };
            let token = CancellationToken::new();
            self.tokens.insert(id, token.clone());
            tasks.push(spawn_conversion(paths.clone(), req, id, token));
        }
        Task::batch(tasks)
    }
    fn running_count(&self) -> usize {
        self.items.iter().filter(|i| matches!(i.phase, Phase::Running { .. })).count()
    }
    fn cancel_token(&mut self, id: &ItemId) {
        if let Some(t) = self.tokens.remove(id) { t.cancel(); }
    }
    fn add_files(&mut self, paths: Vec<PathBuf>) {
        let mut ignored = 0usize;
        let mut queue: VecDeque<PathBuf> = paths.into(); // 支持拖入文件夹，自动展开
        while let Some(p) = queue.pop_front() {
            if p.is_dir() {
                if let Ok(entries) = std::fs::read_dir(&p) {
                    for e in entries.flatten() { queue.push_back(e.path()); }
                }
            } else if util::is_supported(&p) {
                if self.items.iter().any(|i| i.input == p) { continue; } // 去重
                let output = util::planned_output(&p, self.config.output_dir.as_deref());
                self.items.push(Item {
                    id: NEXT_ID.fetch_add(1, Ordering::Relaxed),
                    input: p,
                    output,
                    phase: Phase::Queued,
                });
            } else {
                ignored += 1;
            }
        }
        if ignored > 0 {
            self.status = format!("已忽略 {ignored} 个不支持的文件（仅支持 MP4 / MOV / M4V）");
        }
    }
    fn relocate_outputs(&mut self) {
        let dir = self.config.output_dir.clone();
        for item in &mut self.items {
            if matches!(item.phase, Phase::Queued | Phase::Failed(_) | Phase::Canceled | Phase::Skipped) {
                item.output = util::planned_output(&item.input, dir.as_deref());
            }
        }
    }
    fn save_config(&self) -> Task<Message> {
        let cfg = self.config.clone();
        Task::perform(async move { config::save(&cfg).await }, |_| Message::Ignore)
    }
    // ---------- subscription ----------
    pub fn subscription(&self) -> Subscription<Message> {
        Subscription::batch([
            // 拖拽（iced 0.13 的 listen_with 带 window::Id 第三参；0.12 去掉即可）
            iced::event::listen_with(|event, _status, _id| match event {
                iced::event::Event::Window(iced::window::Event::FileDropped(path)) => {
                    Some(Message::FilesDropped(vec![path]))
                }
                _ => None,
            }),
            // 快捷键：Ctrl+O 添加文件，Ctrl+Enter 全部转换
            iced::keyboard::on_key_press(|key, modifiers| {
                use iced::keyboard::{key::Named, Key, Modifiers};
                let ctrl = modifiers.contains(Modifiers::CTRL);
                match key {
                    Key::Character(c) if ctrl && c.as_ref().eq_ignore_ascii_case("o") => {
                        Some(Message::PickFiles)
                    }
                    Key::Named(Named::Enter) if ctrl => Some(Message::StartAll),
                    _ => None,
                }
            }),
        ])
    }

        match &self.config.output_dir {
            Some(d) => d.display().to_string(),
            None => "输出：与源文件同目录".into(),
        }

    fn total_progress(&self) -> f32 {
        if self.items.is_empty() { return 0.0; }
        let sum: f32 = self.items.iter()
            .map(|i| match i.phase {
                Phase::Running { progress } => progress,
                Phase::Done { .. } => 100.0,
                _ => 0.0,
            })
            .sum();
        sum / self.items.len() as f32
    }
    fn summary(&self) -> String {
        if self.items.is_empty() { return "就绪".into(); }
        let done = self.items.iter().filter(|i| matches!(i.phase, Phase::Done { .. })).count();
        let failed = self.items.iter().filter(|i| matches!(i.phase, Phase::Failed(_))).count();
        let running = self.running_count();
        format!(
            "共 {} · ✅ {} · ❌ {} · ⏳ {} · 总进度 {:.0}%",
            self.items.len(), done, failed, running + (self.items.len() - done - failed - running),
            self.total_progress()
        )
    }
    fn has_pending(&self) -> bool {
        self.items.iter().any(|i| matches!(
            i.phase, Phase::Queued | Phase::Failed(_) | Phase::Canceled | Phase::Skipped
        ))
    }
    fn has_finished(&self) -> bool {
        self.items.iter().any(|i| matches!(
            i.phase, Phase::Done { .. } | Phase::Failed(_) | Phase::Canceled | Phase::Skipped
        ))
    }

/// 单项转换任务：进度实时回传 + 结束消息；CancellationToken 负责取消
fn spawn_conversion(paths: FfmpegPaths, req: Request, id: ItemId, cancel: CancellationToken)
    -> Task<Message>
{
    // 0.12 中为 iced::subscription::channel(id, 16, ...)
    Task::stream(iced::stream::channel(move |tx| {
        let mut tx_done = tx.clone();
        let progress = move |pct: f32| {
            // 进度丢一两帧无所谓 → 非阻塞 try_send
            let mut tx = tx.clone();
            let _ = tx.try_send(Message::Progress(id, pct));
        };
        async move {
            let result = convert::run(&paths, req, cancel, progress).await;
            let _ = tx_done
                .send(Message::Finished(id, result.map(|d| d.as_secs_f64())))
                .await;
        }
    }))
}
fn item_view(item: &Item) -> Element<'static, Message> {
    let (icon, status) = match &item.phase {
        Phase::Queued => ("⏳", "等待中".to_string()),
        Phase::Running { .. } => ("🔄", "转换中…".to_string()),
        Phase::Done { secs } => ("✅", format!("{secs:.1}s 完成")),
        Phase::Failed(e) => ("❌", e.clone()),
        Phase::Canceled => ("🚫", "已取消".to_string()),
        Phase::Skipped => ("⏭️", "输出已存在，跳过".to_string()),
    };
    let name = item.input.file_name().map(|s| s.to_string_lossy().into_owned()).unwrap_or_default();
    let out_name = item.output.file_name().map(|s| s.to_string_lossy().into_owned()).unwrap_or_default();
    let info = match &item.phase {
        Phase::Running { progress } => progress_bar(0.0..=100.0, *progress).into(),
        _ => text(item.input.display().to_string()).size(11).into(),
    };
    let body = column![
        row![
            text(format!("{name} → {out_name}")).size(13),
            horizontal_space(),
            text(status).size(12),
        ],
        info,
    ]
    .spacing(4);
    let mut actions = row![].spacing(6);
    actions = match &item.phase {
        Phase::Queued => actions.push(button("启动").on_press(Message::StartItem(item.id))),
        Phase::Running { .. } => actions.push(button("取消").on_press(Message::Cancel(item.id))),
        Phase::Done { .. } => actions.push(button("📂 打开").on_press(Message::OpenOutput(item.id))),
        _ => actions.push(button("↻ 重试").on_press(Message::StartItem(item.id))),
    };
    if !matches!(item.phase, Phase::Running { .. }) {
        actions = actions.push(button("✕").on_press(Message::Remove(item.id)));
    }
    row![text(icon).size(20), body, actions]
        .spacing(12)
        .align_y(Vertical::Center)
        .into()
}
```

| 平台 | 做法 |
|---|---|
| Windows | `cargo build --release`，把 `vidly.exe + ffmpeg.exe + ffprobe.exe` 放同一目录打成 zip（查找逻辑优先 exe 同目录，`windows_subsystem` 已隐藏控制台） |

| Linux | 构建deg安装包，找一个免费签名 |

**许可证提醒**：常见预编译 ffmpeg 多为 GPL 构建，闭源分发你的程序需自编译 LGPL 版（`--disable-gpl`、去掉 GPL 组件——remux 用不到编码器，LGPL 完全够用），或干脆开源你的程序。

## 七、版本差异速查（编译报错先看这里）

- iced **0.12 → 0.13**：`Command` → `Task`；`subscription::channel` → `stream::channel`；`listen_with` 多了 `window::Id` 参数；按钮新增 `on_press_maybe`
- 若你的 iced 版本 `FileDropped` 变体带坐标（`(PathBuf, Point)`），用 `_` 接住第二个参数即可
- 中文显示为方框：iced 0.13 的 cosmic-text 通常能自动回退系统字体；不行就 `.font()` 内嵌中文字体并 `.default_font(...)` 指定
- `out_time_ms` 单位实为微秒（ffmpeg 历史遗留），代码已处理
